Verify the download

{{BOOT}}

trust, but check. it takes a minute.

Two checks. The checksum shows the file arrived whole. The signature shows the checksums come from us.

  1. Get the files

    Into one folder:

    • {{ISO}}the image, from Download
    • SHA256SUMSits checksum, beside the image
    • SHA256SUMS.sigthe signature on the checksums
    • allowed_signersour public keys

  2. Confirm the checksum

    Linux

    sha256sum -c --ignore-missing SHA256SUMS

    macOS

    grep {{ISO}} SHA256SUMS | shasum -a 256 -c

    Windows

    Get-FileHash {{ISO}}

    Linux and macOS print

    {{ISO}}: OK

    On Windows, compare the hash it prints with the line for the image in SHA256SUMS.

  3. Check the signature

    ssh-keygen -Y verify -f allowed_signers -I omaboot -n omaboot-release -s SHA256SUMS.sig < SHA256SUMS

    It prints

    Good "omaboot-release" signature for omaboot with ED25519 key {{FP_RELEASE}}

    Anything else: don't use the image. {{CONTACT Please [tell us].}}

    ssh-keygen comes with macOS and Linux (OpenSSH 8.1 or newer). On Windows, run it in WSL or Git Bash.

Why you can trust it

Built in public
GitHub Actions builds each release from a tagged commit of the public image repository: Omarchy's own ISO build at a named upstream commit, plus our changes as a short series of readable commits. Every release links its build log.
Official packages
Every package is pinned to the version on the official Omarchy ISO of the same release, from the Arch Linux Archive, Omarchy's stable channel and t2linux. pacman checks each signature as it installs.
A difference report
Each release is compared with the official ISO, package by package and file by file, and every difference is explained. The latest numbers
Little of our own
We build only the tester and a few patched kernel modules ourselves. The build log shows that rebuilding those modules without our patches gives the official ones.
Key off the builder
The build never sees the signing key. The maintainer checks the build, then signs the checksums on their own computer.
