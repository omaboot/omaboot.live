Fixes

OmaBoot? Live runs real Omarchy, plus a few fixes stock Omarchy doesn't have yet, so a Mac that needs one can still be tested. Each one acts only on the hardware it's for, and only in the live system: nothing is written to your Mac.

A report lists the fixes that took effect on the Mac. On {{DIO}}, the results they change still count for the configuration, marked with OmaBoot? <fix> and linked here. In the console, catalog fixes shows which fixes the catalog lists for the Mac and whether each took effect.

Where fixes really happen

A fix here is a stopgap. The lasting fix lands upstream, where every Mac gets it: the Linux kernel, t2linux, or Omarchy itself. Once it ships in Omarchy, OmaBoot? Live drops its own copy, and a new report shows the result without the fix. Where each fix comes from and where it's heading is on {{DIO}}'s fixes page.
